Задача: построить фактлист главы ch$1 — контракт, по которому потом пишется проза. Прозу НЕ писать.

Прочитай: `story/state.md`, `story/plan/beats.md`, `story/plan/synopsis.md`, `story/canon/characters.md`, `story/canon/world.md`, `story/canon/lexicon.md`, последнюю главу в `story/draft/` (какой hook нужно оплатить).

Сделай:

1. Сцены главы. Если есть утверждённая карта сцен (`story/plan/scenes/actN.md`) — сцены NN.1–NN.3 берутся ИЗ НЕЁ, не изобретай. Заполни карточку `story/plan/scene-cards/ch$1.md` по карте: цель, конфликт, поворот, выход, материал — из сцены. Если карты нет — придумай 3 сцены сам и запиши карточку по шаблону `_template.md`.
2. Фактлист `story/plan/sheets/ch$1.md` по шаблону `story/plan/sheets/_template.md`. Строго:
   - 3 сцены × ~1000 слов, каждой сцене — 2–4 факта, не больше;
   - каждый факт заполнен по всем колонкам: Факт / Ожидание / Наблюдение / Вывод / Реплика / Термины;
   - «Ожидание» — что читатель должен знать ДО поворота. Если у факта нет ожидания — поворот не сработает;
   - «Наблюдение» — конкретика глазами POV (вещи, звуки, надписи), не абстракция;
   - «Вывод» звучит в тексте только после наблюдения;
   - «Термины» — точные написания из lexicon.
3. Весовая проверка (раздел в конце листа): если сцена перегружена — предложи, что перенести.

Покажи фактлист целиком. ОСТАНОВИСЬ. Жди утверждения автора. Автор может править таблицу прямо в файле.

ЗАПРЕЩЕНО: писать прозу, создавать draft, обновлять state, коммитить.
