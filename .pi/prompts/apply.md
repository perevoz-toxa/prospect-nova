Утверждённый выбор автора: $@

Если это номер — утверждён соответствующий вариант из `/next`. Если это текст автора — он утверждён как есть, и важнее любого предложенного варианта.

Порядок работы:

1. Создай карточку сцены по шаблону `story/plan/scene-cards/_template.md` для следующей главы, сохрани в `story/plan/scene-cards/chNN.md`. Поля: POV, место, бит, цель POV, конфликт, поворот, исход, hook, `must_mention`, `must_not`, word_target = 3000.
2. Напиши главу **тремя битами по ~1000 слов**: бит 1, бит 2, бит 3 — каждый как отдельный проход, с проверкой, что бит выполняет свою часть карточки. Сохрани в `story/draft/chNN.md`.
3. Проверь объём: `wc -w story/draft/chNN.md`. Цель 3000, допуск ±10%.
4. Проверки: POV один, нет утечки восприятия, нет нарушений `story/canon/`, нет пересказа предыдущих глав.
5. Обнови `story/state.md`: сюжетная точка, кто где, кто что знает, открытые нити, закрытые нити.
6. Допиши в `notes/decisions.md`: глава, принятое решение, почему, что стало невозможным позже.
7. `git add -A` и `git commit -m "chNN: <формулировка решения>"`.

Покажи: номер главы, объём по словам, список новых фактов, внесённых в `state.md`.
