Полный прогон главы ch$1. Ты — дирижёр: выполняй шаги по порядку и ОСТАНАВЛИВАЙСЯ на каждой точке авторского решения.

Шаг 1. Выполни команду `/sheet $1`. Покажи фактлист. **СТОП** — автор утверждает или правит таблицу (он скажет «утверждаю» / «правлю» / даст правки).

Шаг 2. После утверждения выполни `/write $1` (бит за битом, с проверками).

Шаг 3. Выполни `/check $1`. Покажи отчёт. 
- Все факты доставлены → шаг 4.
- Есть провалы → спроси автора: чинить (`/fix`) или принять с замечаниями (`/accept $1 принимаю с замечаниями: ...`). **СТОП** — ждёт решения.

Шаг 4. `/fix $1 <провалы>` — столько кругов, сколько нужно (fix → check → fix...), максимум 3 круга. Дальше — решение автора.

Шаг 5. Выполни `/accept $1`. Покажи commit и изменения state.

ЗАПРЕЩЕНО: пропускать остановки; переходить к следующей главе; обновлять state до шага 5.
