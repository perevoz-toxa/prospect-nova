Задача: написать ch$1 по контракту `story/plan/sheets/ch$1.md`. Фактлист утверждён автором.

Прочитай: фактлист, карточку главы, `story/canon/characters.md`, `story/canon/lexicon.md`, последнюю главу в `story/draft/` (если есть — держи её тон и ритм).

Пиши СТРОГО по одной сцене:

1. Возьми сцену 1 фактлиста. Её строки фактов — цитируй себе в промпт. Напиши ~1000 слов.
2. Проверь сцену: `wc -w` (допуск ±10%); каждый термин сцены найди в тексте (`grep`). Не прошёл — перепиши сцену, не идя дальше.
3. Так же сцена 2, потом сцена 3. Сшей в `story/draft/ch$1.md` — итог ~3000 слов.
4. Каждый факт доставляется по цепочке: ожидание → наблюдение → вывод. Вывод без наблюдения запрещён.

Правила доставки (важнее красоты):
- факт из листа обязан быть в тексте; факт не в листе — не появляется;
- референт называется прямо («балки с литерой П»), не местоимением и не намёком;
- повороту предшествует ожидание — читатель успел представить «как должно быть».

ЗАПРЕЩЕНО: обновлять state, canon, decisions; коммитить; менять фактлист; писать следующую сцену, пока текущая не прошла проверки.

В конце покажи: объём каждой сцены и итог, список терминов с вердиктом найдено/нет. Глава ещё НЕ принята — дальше /check.
