Задача: провести ch$1 через ворота. Условие прохода — последний /check дал все факты `доставлен`, либо автор явно сказал: $2

Порядок:

1. Перечитай последний отчёт /check. Если остались провалы и автор не дал явного «принимаю» — СТОП, сообщи, что ворота закрыты, запусти /fix.
2. Обнови `story/state.md` — СТРОГО ИЗ фактлиста `story/plan/sheets/ch$1.md` и карточки сцены: точка, сцены в движении, знания, открытые/закрытые нити. Не из прозы, не из памяти разговора.
3. Новые факты листа, которых нет в `story/canon/` — в раздел «Факты, отсутствующие в каноне».
4. Допиши `notes/decisions.md`: формулировка решения главы, почему, что закрыто.
5. Если в ходе главы были отвергнутые ходы — `notes/rejected.md`.
6. `git add -A && git commit -m "chNN: <формулировка решения>"`.

Покажи: commit hash, список изменений state (что добавилось/закрылось), факты для канона.

ЗАПРЕЩЕНО: принимать главу с провалами без явного разрешения автора; обновлять state из прозы.
