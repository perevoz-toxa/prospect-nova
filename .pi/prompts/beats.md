Утверждённая арка: $@

Если это номер — утверждён соответствующий вариант `/arcplan`. Если текст автора — он утверждён как есть и важнее всех предложений.

Порядок:

1. Прочитай `story/state.md`, `story/plan/synopsis.md`, `story/canon/*`, все главы в `story/draft/`, `notes/decisions.md`.
2. Перепиши `story/plan/beats.md` по его шаблону: один бит = одна глава = 3000 слов. Каждый бит: POV, место/время, событие, функция (что бит делает для сюжета), изменение, hook.
3. В начале `beats.md` запиши: утверждённую форму арки, мотор, повороты, план закрытия каждой нити.
4. Проверь: каждая открытая нить из `state.md` имеет главу закрытия; каждая глава имеет функцию; нет двух подряд глав одного типа; финал определён.
5. Допиши в `notes/decisions.md`: утверждённая арка, почему, какие ходы теперь невозможны.
6. `git add -A && git commit -m "арка: <форма>"`.

Покажи: список битов с одной строкой на каждый, список нитей с главой закрытия. Напомни автору следующий шаг: `/scenes <акт>` — карта сцен акта до прозы.
