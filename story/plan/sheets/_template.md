# Фактлист — шаблон

Сохраняется командой /sheet в `story/plan/sheets/chNN.md`. Фактлист — КОНТРАКТ главы: проза, state и канон производны от него, не наоборот.

Колонки строки факта:

- **#** — номер факта (на него ссылаются /check и /accept)
- **Факт** — что читатель должен унести из главы (одно предложение)
- **Ожидание** — что читатель должен знать/представлять ДО поворота; без этого нарушение не ощущается
- **Ннаблюдение** — что POV видит глазами: конкретика, вещи, звуки, надписи
- **Вывод** — что из этого следует; звучит в тексте только ПОСЛЕ наблюдения
- **Реплика** — точная фраза, несущая факт (или «—», если факт без реплики)
- **Термины** — 1–3 слова-якоря из `canon/lexicon.md` для grep-проверки

```
# Фактлист — chNN
Бит: NN «название» (beats.md)
POV: —
word_target: 3000
Карточка сцены: story/plan/scene-cards/chNN.md

## Бит 1 — <сцена> (~1000 слов, факты 1–3)

|---|---|---|---|---|---|---|
| 1 | | | | | | |

## Бит 2 — <сцена> (~1000 слов, факты 4–6)
| # | Факт | Ожидание | Наблюдение | Вывод | Реплика | Термины |
|---|---|---|---|---|---|---|

## Бит 3 — <сцена> (~1000 слов, факты 7–9)
| # | Факт | Ожидание | Наблюдение | Вывод | Реплика | Термины |
|---|---|---|---|---|---|---|

## Весовая проверка
Каждый бит: 2–4 факта, одна цель сцены, ≤3 новых имени. Если бит перегружен — разделить или перенести факт в другой бит.
```
