# Фактлист — шаблон

Сохраняется командой /sheet в `story/plan/sheets/chNN.md`. Фактлист — КОНТРАКТ главы: проза, state и канон производны от него, не наоборот. Глава = 3 сцены по ~1000 слов; сцены берутся из карты сцен (`story/plan/scenes/`), если она утверждена.

Колонки строки факта:

- **#** — номер факта (на него ссылаются /check и /accept)
- **Факт** — что читатель должен унести из главы (одно предложение)
- **Ожидание** — что читатель должен знать/представлять ДО поворота; без этого нарушение не ощущается
- **Наблюдение** — что POV видит глазами: конкретика, вещи, звуки, надписи
- **Вывод** — что из этого следует; звучит в тексте только ПОСЛЕ наблюдения
- **Реплика** — точная фраза, несущая факт (или «—», если факт без реплики)
- **Термины** — 1–3 слова-якоря из `canon/lexicon.md` для grep-проверки

```
# Фактлист — chNN
Бит: NN «название» (beats.md)
POV: —
word_target: 3000
Карточка главы: story/plan/scene-cards/chNN.md
Сцены: из карты actN (scene NN.1–NN.3) / придуманы /sheet

## Сцена 1 — <название> (~1000 слов, факты 1–3)

Каждая сцена: 2–4 факта, одна цель, ≤3 новых имени. Если сцена перегружена — разделить или перенести факт в другую сцену.
```
