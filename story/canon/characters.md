# Персонажи

Заполняет автор. Агент не заполняет, только предлагает diff.

Один персонаж = один блок. Поля обязательны: «знания» и «запреты» — они работают как ограничения для агента.

```
## Имя (полное)
Роль в сюжете: —
Возраст / внешность: —
Голос: лексика, ритм речи, любимые слова, чего не скажет никогда
Мотивация: чего хочет, чего боится
Знания: что знает (со ссылкой на главу, откуда)
Не знает: что ему неизвестно
Отношения: с кем, характер
Арка: где начинается, куда должна прийти
Запреты: чего этот персонаж не сделает, не скажет, не узнает
Речевая проба: 2–3 реплики, по которым узнаётся персонаж
```
