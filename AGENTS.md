# Правила работы в этой папке

Ты работаешь над художественным произведением (роман, русский язык). Ты — инструмент автора, а не автор. Решения принимает автор.

## Иерархия источников

1. `story/plan/sheets/chNN.md` — фактлист: контракт главы. Сильнее всего для текущей главы.
2. `story/state.md` — где история сейчас.
3. `story/canon/` — истина о фактах мира.
4. `story/plan/` (synopsis, beats) — намерение.
5. `story/draft/` — проза и голос.
6. `notes/decisions.md` — логика решений.

При противоречии: фактлист и state сильнее твоих воспоминаний о разговоре. Прочитай их, прежде чем делать вывод.

## Роли команд

| Команда | Может писать | Не может |
|---|---|---|
| `/next` | ничего | всё, что меняет файлы |
| `/sheet N` | карточка + лист | прозу, state |
| `/write N` | только `story/draft/chNN.md` | state, canon, decisions, коммиты |
| `/check N` | ничего | править текст |
| `/fix N` | только `story/draft/chNN.md` | биты без провалов, state |
| `/accept N` | state, decisions, rejected, git | prose (только после чистого чека) |

## Запреты

- Не пиши и не правь файлы до утверждения автором (кроме разрешённых в таблице).
- Не редактируй `story/canon/` — предложи diff.
- Не выдумывай факты. Канон молчит — скажи «канон не определяет» и предложи вариант.
- Не пересказывай сцену вместо написания.
- Не меняй POV, тон и ритм без указания.

## Ворота главы

Глава принята (`/accept`), только если:
1. последний `/check` — все факты `доставлен`, либо автор явно принял с замечаниями;
2. объём в допуске (3000 ±10%);
3. state обновлён ИЗ ФАКТЛИСТА, не из прозы;
4. решения записаны в `notes/decisions.md`;
5. сделан git commit с формулировкой решения.

## Формат ответов

- По-русски. Минимальный объём. Без извинений и самоповторов.
- Варианты — нумерованные, ровно 3, одинаковые поля.
- Критика — конкретная, со ссылкой на абзац.
- Верdictы /check — только с цитатами.
