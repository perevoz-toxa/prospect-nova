# Prospect Nova

Роман. Русский язык. Глава = 3000 слов, генерация тремя битами по ~1000 слов.

## Рабочий цикл

1. `/next` — агент читает состояние истории и выдаёт **3 варианта** следующего сюжетного хода. Ничего не пишет.
2. Автор отвечает: `1`, `2`, `3` — или своё развитие.
3. `/apply <выбор>` — агент прописывает утверждённое в главу, обновляет состояние, журнал решений, делает git commit.
4. Отвергнутые варианты сохраняются в `notes/rejected.md`.

## Структура

| Путь | Назначение |
|---|---|
| `story/state.md` | Единственный источник истины о том, где история сейчас |
| `story/plan/` | Synopsis, биты, карточки сцен |
| `story/canon/` | Персонажи, мир, хронология, лексикон |
| `story/draft/` | Главы: `ch01.md`, `ch02.md`, ... |
| `notes/decisions.md` | Журнал принятых решений |
| `notes/rejected.md` | Отвергнутые варианты — топливо на будущее |
| `.pi/` | Настройка pi, системные инструкции, команды |

## Запуск

```bash
cd D:/Development/books/prospect-nova
pi
/trust          # разрешить загрузку .pi/settings.json, .pi/prompts, .pi/APPEND_SYSTEM.md
```

После изменения файлов в `.pi/` — `/reload`.

## Модели

- `strata/swift-1.5-iq2_xs` — плотные 27B. Сюжетные решения и проза.
- `lm-studio/qwen/qwen3.6-35b-a3b` — MoE, быстрый. Сканы, экстракция, форматирование.

## Правила

- Агент **не пишет в файлы до утверждения автором**.
- Агент **не редактирует `story/canon/` напрямую** — только предлагает diff.
- Каждое принятое решение = git commit с формулировкой решения.
