# Prospect Nova

Роман. Русский язык. Глава = 3000 слов = 3 сцены по ~1000.

> **Принцип конвейера:** слабый генератор компенсируется дисциплиной.
> Прогресс = проверенные артефакты, а не объём текста.
> Фактлист — контракт главы: проза, state и канон производны от контракта.
> Ворота закрыты по умолчанию: нет чистого аудита — нет коммита.

---

## Быстрый старт

```bash
cd D:/Development/books/prospect-nova
pi
/trust      # разрешить .pi/ (один раз)
/reload     # после любых правок в .pi/
```

Модель по умолчанию — `strata/swift-1.5-iq2_xs`. Всё работает локально, GLM не обязателен.

## Словарь конвейера

| Термин | Что это | Размер | Где живёт |
|---|---|---|---|
| **Канон** | истина о мире: нормы, персонажи, истории | весь мир | `story/canon/` |
| **Арка** | форма книги: мотор, повороты, финал | вся книга | `notes/decisions.md` (после `/arcplan`) |
| **Бит** | глава: одно событие с функцией в сюжете | 3000 слов | `story/plan/beats.md` |
| **Сцена** | единица действия: цель → конфликт → поворот → выход | ~1000 слов | `story/plan/scenes/actN.md` |
| **Факт** | атом контракта: что читатель уносит | 1 строка таблицы | `story/plan/sheets/chNN.md` |
| **Проза** | текст главы | 3000 слов | `story/draft/chNN.md` |

`/next` выбирает **главу**, не сцену. Сцены — внутренности главы.

## Один элемент на всех уровнях (сквозной пример)

Как норма мира доезжает до прозы — на примере знака руки:

```
КАНОН   world.md:      «Знак запроса слова: правая рука на левое плечо,
                       взгляд на того, чьё разрешение хочешь получить»
АРКА    финал:         экипаж встречает нового мозга этим же знаком
ЛЕГЕНДА legends.md:    у нормы должна быть история-источник
                       (сейчас — дыра: «нужна разработка»)
БИТ     beats.md:      «Бит 05 — Экзамен: Анна впервые экзаменует»
СЦЕНА   scenes/act1:   «Сцена 5.2 — Ребёнок просит слова»
ФАКТ    sheets/ch05:   | 4 | Анна видит знак ребёнка и разрешает кивком | ... |
ПРОЗА   draft/ch05.md: «Мальчик положил правую ладонь на левое плечо и
                        замер. Анна кивнула — и зал зашептался.»
```

Правило согласованности: норма без истории в `legends.md` — дыра, `/arc` её найдёт.

## Путь новой главы

### 0. Карта сцен (раз на акт, до прозы)

```
/scenes 1-8
```

Агент читает биты, канон, `legends.md` и пишет `story/plan/scenes/act1.md`:
3 сцены на каждую главу акта + проверки (однотипные подряд, POV-баланс,
истории без сцены-носителя). Показывает карту. **СТОП** — ты правишь файл
руками или говоришь правки, потом «утверждаю».

Пример сцены из карты:

```
### Сцена 5.2 — Ребёнок просит слова
POV: Анна
Место / время: учебный модуль, утро
Цель: Анна проводит первый в её практике экзамен по мышлению
Конфликт: ребёнок думает медленно, за ней наблюдает весь класс
Поворот: ответ ребёнка оказывается точнее ожидаемого — Анна ошиблась в расчёте
Выход: экзамен сдан; Анна впервые чувствует вес слова «принято»
Материал: legends.md #3 («сначала воздух, потом любопытство» звучит от Анны)
```

### 1. Выбор главы

```
/next
```

Агент выдаёт ровно 3 варианта следующей главы. Пример (сокращён):

```
### Вариант 1 — Экзамен Анны
Суть: Анна впервые экзаменует ребёнка по мышлению — и сама ошибается в расчёте.
Следствие: Анна из «лучшей пары» становится экзаменатором поколения.
Риск: бытовой эпизод без ставки; нужна цена ошибки.
Канон: +экзамен изнутри; легенда #3 получает сцену-носитель.
Объём: ~3000.
```

Ты отвечаешь: `1` / `2` / `3` — или своё развитие своими словами. Твоё развитие сильнее всех вариантов.

### 2. Контракт (фактлист)

```
/apply 5        ← дирижёр сам вызовет /sheet, /write, /check...
```
или по шагам: `/sheet 5`.

Сцены берутся из утверждённой карты — агент их не изобретает. По каждой
сцене он раскладывает факты: что читатель должен унести, каким ожиданием
это подано, что POV видит, какой вывод звучит. Пример строк фактлиста:

```
## Сцена 2 — Ребёнок просит слова (~1000 слов, факты 4–6)
| # | Факт | Ожидание | Наблюдение | Вывод | Реплика | Термины |
|---|---|---|---|---|---|---|
| 4 | Анна видит знак ребёнка и разрешает кивком | знак введён сценой 1 (класс молчит) | правая ладонь на левом плече, взгляд в глаза | любой взрослый может дать слово | — | знак, экипаж |
| 5 | Экзамен проверяет мышление, не знания | урока не было — был разбор | мальчик отвечает «не знаю» там, где класс хором знал | «не знаю» — честный ответ, не провал | «Не знаю» — тоже ответ | экзамен |
```

**СТОП** — ты читаешь лист. Правь прямо в файле (колонки, факты, реплики),
потом скажи «утверждаю». Это самая важная твоя точка контроля.

### 3. Проза

`/write 5` — агент пишет сцену за сценой (~1000 слов каждая), после каждой
проверяет объём (`wc -w`, допуск ±10%) и термины (`grep`). Сцена не прошла —
переписывается, следующая не начинается. Глава сшивается в `draft/ch05.md`.
State и коммиты на этом шаге запрещены.

### 4. Холодный читатель

```
/model lm-studio/qwen/qwen3.6-35b-a3b     ← переключиться на быструю
/check 5
```

Читатель видит ТОЛЬКО текст главы. Сначала восстанавливает факты из текста,
потом сверяет с фактлистом. Пример отчёта:

```
| # | Факт (из листа) | Вердикт | Цитата из текста |
|---|---|---|---|
| 4 | Анна видит знак ребёнка | доставлен | «Мальчик положил правую ладонь на левое плечо и замер» |
| 5 | Экзамен проверяет мышление | искажён | «экзамен был несложным» — вывод без наблюдения |

Вопросы читателя: почему класс молчал? кто имеет право экзаменовать?
```

Вердикт без цитаты запрещён. Провалы → ремонт.

### 5. Ремонт и ворота

```
/fix 5 «факт 5: вывод без наблюдения»     ← перегенерация только проваленной сцены
/check 5                                  ← снова (до 3 кругов)
/accept 5                                 ← ворота: state обновляется ИЗ ФАКТЛИСТА,
                                             решения в notes, git commit
```

`/accept` не пройдёт с провалами, пока ты явно не скажешь
`/accept 5 принимаю с замечаниями: ...`.

Коммит выглядит так: `ch05: экзамен Анны; легенда #3 оплачена сценой`.

## Уровень арки (когда накопились главы или меняется замысел)

```
/arc               → слабые места (8 категорий) + вопросы автору. СТОП.
  ты отвечаешь (можно спорить, можно «не знаю, предложи»)
/arcplan "ответы"  → 3 арки РАЗНОЙ формы: мотор, повороты, закрытие нитей,
                     финал, что каждый выбор запрещает. СТОП.
  ты: номер или своя форма
/beats 2           → арка → биты (бит = глава), коммит
/scenes 1-8        → карта сцен первого акта. СТОП.
```

`/arc` на GLM видит все главы целиком; локально работает до ~15 глав.
`/arc` также проверяет: каждая норма канона имеет историю в `legends.md`,
каждая нить `state.md` имеет главу закрытия.

## Уровень мира

| Файл | Кто заполняет | Когда |
|---|---|---|
| `canon/world.md`, `characters.md`, `timeline.md`, `legends.md` | ты решаешь — агент вносит | при смене концепции |
| `canon/lexicon.md` | агент пополняет с твоего утверждения | после каждой главы |
| `notes/open-questions.md` | только ты | вопрос закрыт → ответ в канон, строка удалена |
| `notes/author-intent.md` | только ты (агенту — не переносить в текст) | твои причины и смыслы |
| `story/plan/synopsis.md` | ты правишь свободно | после правки = истина |

Агент канон не редактирует — только предлагает diff.

## Модели

| Модель | Роль |
|---|---|
| `strata/swift-1.5-iq2_xs` | `/next`, `/sheet`, `/write`, `/fix`, `/scenes`, `/beats` |
| `lm-studio/qwen/qwen3.6-35b-a3b` | `/check`, `/state` — быстрые механические проверки |
| `zai/glm-5.3` (опционально) | `/arc`, `/arcplan`, полировка — большой контекст |

Переключение: `/model <провайдер/модель>`. Честный холодный читатель —
отдельным процессом, без контекста проекта:

```bash
pi --model lm-studio/qwen/qwen3.6-35b-a3b --print @story/draft/ch05.md \
  "Восстанови из текста: что за место, что нашли, как поняли, кто за этим, что теперь. Только из текста."
```

## Ретро: прокачка конвейера

После каждой главы — 2 минуты: какие факты падали в `/check` и почему?

- факт «отсутствует» → сцена перегружена → меньше фактов на сцену;
- факт «искажён» → допиши правило в `.pi/prompts/write.md`;
- модель игнорирует запрет → перенеси запрет в начало промпта;
- систематическое → правило в `.pi/APPEND_SYSTEM.md`.

Промпты — файлы в git. Правка промпта = коммит `конвейер: <что ужесточено>`.

## Правила (защита от дрейфа)

- Агент не пишет файлы до твоего утверждения (роли команд — `AGENTS.md`).
- `story/canon/` агент не редактирует — только diff.
- `story/state.md` обновляется только `/accept` и только из фактлиста.
- Факт не в фактлисте — не появляется в прозе. Факт в фактлисте — обязан быть доставлен.
- Коммит главы = формулировка решения.

## Структура

```
story/
├── state.md              # где история. Обновляется ТОЛЬКО /accept
├── plan/
│   ├── synopsis.md       # замысел (правишь ты)
│   ├── beats.md          # биты (бит = глава = 3000 слов)
│   ├── scenes/           # карты сцен актов (сцена = ~1000 слов)
│   ├── scene-cards/      # карточки глав
│   └── sheets/           # ФАКТЛИСТЫ — контракты глав
├── canon/                # мир, персонажи, хронология, легенды, лексикон
└── draft/                # главы
notes/
├── decisions.md          # журнал решений
├── rejected.md           # отвергнутые варианты (топливо)
├── open-questions.md     # открытые вопросы канона (решает автор)
└── author-intent.md      # твои смыслы (не для текста)
archive/
└── test-run-1/           # первый прогон (git tag test-run-1)
.pi/                      # команды и правила агента
```
