# Журнал решений

Одно принятое решение = одна запись. Формулировка решения важнее его содержания: по ней восстанавливается логика книги.

```
## chNN — <формулировка решения>
Принято: что именно утверждено (вариант N или развитие автора)
Почему: мотив автора
Последствия: что стало возможным
Закрыто: что стало невозможным позже
Глава: chNN, commit <hash>
```
