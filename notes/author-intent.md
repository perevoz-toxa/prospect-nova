# Намерения автора (не канон)

Контекст замысла для агента. НЕ переносить в текст книги. В книге соответствующие решения аргументируются практической стороной (см. канон, `story/canon/world.md`).

## Почему демонтированы рода (метафизическая причина — авторская)

- Люди созданы высшим космическим разумом по своему подобию. Система «папа+мама → ребёнок» введена, чтобы объяснить в информационном поле людей понятие «создания по подобию».
- Но по факту родители не создают: они зачинают. Устройство тела, психики, встроенной нейросети — всё спроектировано разумной силой природы. Ничего из этого родители не продумали.
- Из ошибочного представления «родители — создатели» вырастает ложный авторитет родителя. Через него глупые поведенческие программы передаются по наследству без проверки.
- Авторитет должен принадлежать настоящему создателю — высшему космическому разуму. Для этого убрана причина ложного авторитета — родовая система.

## Следствие для книги

В тексте мира — только практическая аргументация (инженерная логика корабля): авторитет доказывается делом, род делит экипаж, воспитание — функция, оценка — зрячая, любовь к детям — распределена. См. `story/canon/world.md`, раздел «Почему демонтированы рода».
